# Mewoods

**Bem vindo!**
Este projeto foi desenvolvido na primeira Game Jam do Senai em 2025.

## Visão Geral

**Mewoods** é um jogo plataforma 2d, onde você é um ser da floresta e está em busca de ruínas antigas para resolver um mistério. 

## Mecânicas

- Se aventure pela floresta e tente sobreviver.
